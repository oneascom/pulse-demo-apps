# Pulse Login Demo – Vue

A reference implementation of a login page built with Vue and Pulse.

This demo was created to test the use of Pulse components in a Vue application and to provide a working example for development teams evaluating or implementing Pulse.

## Purpose

The demo can be used to:

- Test Pulse components in a Vue application
- Demonstrate how Pulse components can be integrated and configured
- Provide a reference for development teams building similar interfaces
- Identify gaps or issues in the Vue/Pulse integration

This is demo and reference code. It is not intended to prescribe the architecture or implementation of a production application.

## Technology

- Vue 3
- TypeScript
- Vite
- Pulse Web Components
- Pulse design tokens
